No stable Papyrus workbench API or command-line interface has been implemented yet. The first experiment exports a shared Rust Button and story; see its [source and run guide](https://github.com/jedt3d/papyrus/blob/main/source/README.md). This section will document stable interfaces as they become available.

Planned coverage includes compatibility profiles, story definitions, diagnostics, runner results, revision identity, and build/reload contracts. Names in the proposal remain design suggestions until confirmed by code.

For current project instructions and the functioning Hugo publishing commands, see the [repository README](https://github.com/jedt3d/papyrus#readme). Follow the [developer diary]({{< relref "diary" >}}) for evidence and decisions.
