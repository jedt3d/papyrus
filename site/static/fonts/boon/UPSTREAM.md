# Boon webfonts

Boon 3.0 by Sungsit Sawaiwan, from [FontUni](https://fontuni.com/boon/).

Source: [fontuni/boon, commit baefcbc3c44737af2aec0a6fc2ccb789b7c0b089](https://github.com/fontuni/boon/tree/baefcbc3c44737af2aec0a6fc2ccb789b7c0b089/fonts/woff2-ttf).

Downloaded on 11 October 2026. The WOFF2 files and `OFL.txt` are unchanged. They use the SIL Open Font License 1.1; the copyright and license are included beside the fonts.

The publishing stylesheet uses Boon's looped Thai glyphs for Thai text, including headings and emphasis. A CSS `unicode-range` keeps Latin text on the fonts configured by the site theme. The files are served by GitHub Pages; this does not change the fonts used in Rust renderer experiments.
